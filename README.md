# TechResolve – IT Troubleshooting & Diagnostics System

TechResolve is a web-based IT troubleshooting and diagnostics application designed to help users identify system-related issues and access basic diagnostic information through a simple and user-friendly interface.

## 🚀 Features

- **System Monitoring:** Displays essential system information.
- **Diagnostics:** Helps identify common system-related issues.
- **Troubleshooting:** Provides useful troubleshooting information.
- **Web Interface:** Simple and user-friendly dashboard.
- **Backend Integration:** Uses Python and Flask to handle application logic.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite / Database Integration

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/TechResolve.git
```

2. Navigate to the project directory:

```bash
cd TechResolve
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate the virtual environment (Windows):

```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run the application:

```bash
python app.py
```

7. Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## 🎯 Project Objective

The objective of TechResolve is to simplify basic IT troubleshooting by providing a centralized web-based platform for accessing diagnostic information and resolving common technical issues.
